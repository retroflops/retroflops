NASA's own description of the guidance system makes a commercial comparison when
it gets to memory. A fully populated computer, the report says, has a capacity
"equivalent to the basic memory capability of the IBM 7090 commercial machine".
The 7090 was what businesses and universities of the period were buying.

The comparison belongs to the report's authors rather than to a later retelling.
It sits in the paragraph introducing the memory modules, and it records what a
large memory looked like in 1970 to the people building one.
