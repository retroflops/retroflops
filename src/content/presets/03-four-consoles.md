# Four consoles, four clocks

Four machines is the most this view will show, and this is the comparison that
earns the fourth column: all four manufacturers stated a main processor clock in
their own hardware documentation, so the row is complete and the multipliers run
from the PlayStation's 33.8688 MHz to the PlayStation 2's 294.912 MHz.

Look at what happens either side of that row.

The floating-point figures do not line up at all. The Dreamcast's number is a
matrix-multiplication peak and the PlayStation 2's is a vendor-stated peak; they
are different comparability groups, so they appear as separate rows and no
multiplier is offered between them. The two older consoles state no
floating-point figure whatsoever.

The memory rows split by role, which is the only way they make sense. Main
memory is compared with main memory and video memory with video memory. The
Nintendo 64's single unified pool sits in a row of its own because it does both
jobs. Dividing it by another machine's main memory alone would quietly overstate
the difference.

The graphics clocks are present for three of the four machines and refuse a
multiplier because the baseline column (the original PlayStation) records no
graphics clock. Every multiplier here is measured against the baseline.
