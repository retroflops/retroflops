# Forty years of home computing

The PAL Commodore 64 and the 8 GB Raspberry Pi 5 are forty-one years apart. The
two allowed ratios measure nominal CPU clock and whole-system memory capacity.
The CPU-clock row compares the main processors. The whole-system-memory row
compares the fitted 64 KiB of RAM with 8 GiB of unified memory. Each pair has
the same metric, scope, and method, so the catalog can show its multiplier.

Neither ratio is a universal measure of speed. The 6510's PAL clock derives from
television timing, while the Raspberry Pi's quad-core Cortex-A76 is a different
processor with a different instruction set, cache hierarchy, and number of
cores. The clock multiplier reports oscillator rates only; it provides no
work-per-second result.

The memory multiplier is similarly narrow. The Commodore 64's whole-system
figure is its 64 KiB RAM; its 20 KiB ROM is banked over that address space and
is deliberately not added. The Raspberry Pi has 8 GiB of unified RAM shared by
its CPU and GPU. Capacity reports installed memory. It leaves access speed and
software capability unmeasured.
